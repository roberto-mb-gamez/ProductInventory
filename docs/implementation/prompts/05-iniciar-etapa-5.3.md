# Iniciar etapa 5.3 — Seguridad

## Prompt para pegar en Codex

Autorizo únicamente la etapa 5.3, si 5.2 está APPROVED. Lee STAGE-5.3-security.md y ADR-006/007. Integra Keycloak en Compose, realm de desarrollo, JWT Bearer validando firma/emisor/audiencia/expiración y Swagger Authorization Code con PKCE. Prueba tokens válidos e inválidos sin desactivar controles de seguridad. No introduzcas RBAC fuera de alcance ni empieces CRUD. Registra evidencia y deja la etapa COMPLETED pendiente de aprobación.

## Formato de respuesta requerido
1. Etapa y estado verificado.
2. Tareas realizadas y archivos cambiados.
3. Pruebas/comandos realmente ejecutados y resultados.
4. Bloqueos o decisiones que necesitan autorización.
5. Archivos de seguimiento actualizados y siguiente paso.

**Instrucción permanente:** El código, los identificadores y los comentarios del proyecto deben permanecer en inglés. Puedes explicarme los resultados en español.
