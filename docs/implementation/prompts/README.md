# Prompts en español para Codex
1. `00-preparar-repositorio.md`: revisión previa sin cambios.
2. `01-iniciar-etapa-5.1.md`: primera ejecución autorizada.
3. `02-revisar-etapa.md`: auditoría antes de aprobar.
4. `03-aprobar-y-avanzar.md`: **solo después de que el usuario decida aprobar**; sustituir `[INDICAR 5.X]`.
5. `04` a `07`: ejecutar la siguiente etapa **solo después de su aprobación anterior**.
6. `08-reanudar-sesion.md`: continuar tras cerrar Codex.
7. `09-corregir-bloqueo.md`: reparar bloqueos.
8. `10-revision-final-git.md`: preparar revisión sin publicar.

Los prompts no sustituyen a `AGENTS.md`, `constraints.md`, ADR ni a los 17 casos de uso.
No ejecutar varios prompts de inicio de etapa a la vez.
