# Iniciar etapa 5.1 — Bootstrap

## Prompt para pegar en Codex

Autorizo únicamente la ejecución de la etapa 5.1. Lee las especificaciones y el archivo STAGE-5.1-bootstrap.md. Marca 5.1 IN_PROGRESS, implementa sus tareas de forma incremental, crea la solución net9.0 y los siete proyectos, DI mínima y GET /health. No implementes lógica de negocio, persistencia, Keycloak ni Docker. Ejecuta restore/build/test y verifica health si el entorno lo permite. Actualiza evidencias y seguimiento. Si cumples los criterios, marca COMPLETED, nunca APPROVED, y detente.

## Formato de respuesta requerido
1. Etapa y estado verificado.
2. Tareas realizadas y archivos cambiados.
3. Pruebas/comandos realmente ejecutados y resultados.
4. Bloqueos o decisiones que necesitan autorización.
5. Archivos de seguimiento actualizados y siguiente paso.
