# Reanudar Codex desde el estado local

## Prompt para pegar en Codex

Lee AGENTS.md, constraints.md, ROADMAP.md, STATUS.md, el archivo de etapa activa, los ADR relevantes y git status. Compara el progreso documentado con los archivos reales. Si la etapa está IN_PROGRESS y autorizada, continúa la siguiente tarea pendiente con TDD y registra evidencias. Si está READY sin autorización, COMPLETED esperando revisión o APPROVED, no empieces trabajo nuevo: informa el siguiente paso. No avances de etapa por iniciativa propia.

## Formato de respuesta requerido
1. Etapa y estado verificado.
2. Tareas realizadas y archivos cambiados.
3. Pruebas/comandos realmente ejecutados y resultados.
4. Bloqueos o decisiones que necesitan autorización.
5. Archivos de seguimiento actualizados y siguiente paso.

**Instrucción permanente:** El código, los identificadores y los comentarios del proyecto deben permanecer en inglés. Puedes explicarme los resultados en español.
